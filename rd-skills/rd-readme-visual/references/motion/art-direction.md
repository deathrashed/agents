# Art direction: no generic generated diagrams

This skill must produce designed explanatory artifacts, not off-the-shelf AI aesthetics. Inspect the project's language and objects first: CLI prompts, data models, pipeline stages, file formats, visible UI, audio waveforms, real paths. Pick ONE visually precise conceptual metaphor, rather than mixing orbit, sparkles, neural nets and gradients.

## Design gates
1. State the actual project fact or process the visual proves. If no grounded fact exists, make an abstract branding mark **clearly decorative** or abstain.
2. Choose one formal system: a measured technical schematic, a tightly typeset terminal documentary, a record-groove/data-track, a hand-numbered diagram, or a seeded generative texture related to the product.
3. Build a hierarchy: primary title, subject, labels, fine instrumentation. Body labels must remain legible at README widths 375 px and 768 px.
4. Palette budget: one accent plus neutrals unless branding requires more. Contrast over glow. Do not force yellow/white onto repositories with different branding.
5. Give motion an explanatory role. Moving particles must follow actual connections; no arbitrary bobbing, blurs, decorative shimmer or floating glyph clouds.
6. Distinctive detail comes from specific grammar: coordinate ticks, meaningful numbering, process-specific terms, asymmetrical negative space, and carefully limited textures.
7. One original composition per project. Vary typographic rhythm, topology and media based on data, not interchangeable prompts. Require a human-readable static frame.
8. Reject fake numbers, fake terminals, fictional output, stock dashboards and generic infinite spinners. Project commands and labels must be verified in source before representing them as functional facts.

## Adapted source principles
- Open Design `motion-design`/`animate`/`review-animations`: motion is functional feedback, explanation or state, restrained and reduced-motion aware.
- Open Design `algorithmic-art`: seeded reproducible texture and mathematically explicit geometry; don't copy upstream artworks.
- Open Design `brandkit`: ownable symbolic system derived from the project's purpose, not random mascots or visual filler.
- Readme Forge: content blocks, global variables and reusable templates; preserve the block architecture, not its HTML/React code or artworks.
