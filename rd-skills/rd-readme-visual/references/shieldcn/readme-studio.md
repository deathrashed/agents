# README Studio

Studio: https://shieldcn.dev/studio ; documentation: https://shieldcn.dev/docs/studio

Visual editor for mixing Markdown/text, headers, badges, charts, tables and images. It can export GitHub-flavoured Markdown; adaptive exports may generate `<picture>` variants. Use it when the user explicitly wants a visual editor or broad visual composition. Keep a repository-owned README as source of truth. Import/export may not preserve custom complex HTML exactly, so diff before merging. Verify generated links, anchor names, brand colours and external assets.
