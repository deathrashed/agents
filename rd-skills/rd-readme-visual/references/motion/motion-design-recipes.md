# Motion composition recipes

## A. Signal-routing schematic
Four exact stages, ordered left-to-right. Each has a diamond port; a dashed event pathway flows between them. Controlled instrument labels and a minimal measured grid. Use when work genuinely moves between stages (audio metadata, ETL, build pipelines).

## B. Documentary terminal
A fixed terminal window, accurate commands, status lines and source evidence. Subtle cursor pulse only if representing a prompt. Real demos should be recorded; illustrative compositions must be labelled as such. Use for CLIs and TUIs.

## C. Orbital architecture atlas
One real central hub with a small number of actual satellites. Three concentric dotted orbits, explicit numbered layers and a callout column. Avoid for linear pipelines. Use for plugin routers, MCP gateways and central-agent systems.

## D. Hand-annotated flow
Recreate measured, slightly irregular ink geometry using deterministic control points, not pure scribbling. Use with `hand-drawn-diagrams` principles, but no external SVG or templates copied without a compatible license.

## E. Data-driven progress strip
A band of truthful values shown at fixed time snapshots. Only move the highlight if it aids interpretation; never animate numeric totals to invent intermediate values.

For each recipe record: content fact, viewport, hierarchy, material, exact labels, time map, static frame and testing notes. Use a reproducible seed.
