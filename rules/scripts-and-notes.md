# Personal scripts and their notes

Sources: TR (script naming, storage, documentation rules), CX (Personal
defaults). These are m3 conventions; the paths are [UNVERIFIED] on cachy,
where the folder is lowercase `~/scripts` [G].

- Script names use Smart Sentence Case with spaces, like a menu command:
  `Convert JSON to CSV.applescript`. Keep acronyms uppercase and extensions
  lowercase. Full rules: m3 `~/Scripts/.docs/FILENAME_RULES.md`. [TR]
- Store scripts in `~/Scripts/<Category>/<Subcategory>/`, with a
  `Script Name.md` doc beside each script. [TR]
- Mirror each doc in the Obsidian vault at `Scripts/<Category>/…`, using
  Capitalised Spaced folder names. Follow the vault's `Scripts/CLAUDE.md`:
  YAML frontmatter (title, description, author: riley, category, language,
  path, tags) and the ten sections, with the source code copied exactly. [TR]
- Music tasks: preserve exact releases, real metadata, provenance and rd's
  genre taxonomy. Keep download → staging → validate → import as separate
  steps. [CX]
- Use rd's own sent prompts when matching rd's writing style. [CX]
